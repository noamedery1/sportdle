# נכסים סטטיים

כל מה שיושב כאן מועתק כמו שהוא ל-`dist/` בזמן הבנייה.

`build.mjs` מזהיר אם אחד מאלה חסר, כי הדף מקשר אליהם ובלעדיהם
מקבלים 404 שקט בפרודקשן:

| קובץ | מה זה | הערה |
|---|---|---|
| `favicon.ico` | אייקון הלשונית | אפשר להעתיק מ-beitardle |
| `icon-32.png` | 32×32 | |
| `icon-180.png` | 180×180, apple-touch | |
| `icon-512.png` | 512×512, ל-manifest | |
| `og.png` | 1200×630, תצוגה מקדימה בוואטסאפ | **חדש — צריך גרסה לחמישה מועדונים**, לא זו של ביתרדל |

`manifest.json` נוצר אוטומטית בבנייה. אם תניח כאן קובץ בשם הזה,
הוא יגבר על המיוצר.

הצבעים לגרפיקה נמצאים ב-`config/clubs.json` תחת `colors.brand`:
בית"ר `#FFC72C` · הפועל ב"ש `#E4002B` · מכבי ת"א `#0033A0` ·
מכבי חיפה `#00843D` · הפועל ת"א `#C8102E`.
